# Contributing to the dpm-assembly repository

This page gives a high-level overview of how to contribute to the development of `dpm-assembly`.

## Issues

Features and bugs are tracked in GitHub issues in this project.

## Testing

Contributions from forks will require review by a contributor before CI is run against them.  You are able to test locally if you configure to point to a local OCI repository.
